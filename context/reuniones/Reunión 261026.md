## Alcance del módulo

### PCAL-01 — Uso del modelo después de compararlo · Sin respuesta

**Pregunta:** ¿El módulo solo debe mostrar las gráficas para comparar modelos, o también se debe guardar el mejor modelo y usarlo para corregir los datos que lleguen después?

**Respuesta:** 

- Solo mostrar graficas
- El administrador Descarga el modelo que el elija para luego subirlo y calibrar las estaciones para tener mejor eficiencia.

### PCAL-02 — Usuarios del módulo · Sin respuesta

**Pregunta:** ¿Quién puede usar el módulo de calibración: solo los administradores o también el público general?

**Respuesta:** Solo para los administradores.

### PCAL-03 — Datos calibrados visibles · Sin respuesta

**Pregunta:** Si se calibran los datos, ¿el público debe ver los datos crudos, los calibrados o ambos? ¿Los datos calibrados se pueden descargar?

**Respuesta:** El publico en general ve los datos en crudo y los datos calibrados no se muestran y solo sirven para entrenar y poder elegir modelos y comparar.
